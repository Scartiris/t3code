# OpenViking 知识库与记忆

在 **设置 → OpenViking** 中选择环境，分别管理知识库和记忆。移动端从环境设置中的 **OpenViking → 知识库与记忆** 进入。

**知识库** 保存文档、说明和参考资料。可以新建文档，在网页中导入 Markdown 或文本文件，搜索内容，打开查看并编辑。文档保存后更新检索索引，agent 可以通过知识库工具查询资料。

**记忆** 保存跨会话使用的事实、偏好、决策和参考信息。可以搜索、查看、新建或编辑内容，选择全局或指定项目范围，设置标签与置顶。置顶记忆在会话开始时载入；已有会话保留启动时的记忆快照，记忆工具始终读取当前内容。

两个部分均可归档与恢复。归档后停止在使用中列表和常规检索中返回；在 **已归档** 中可以恢复。编辑时若内容已被其他客户端或 agent 更新，保存会提示冲突并保留当前草稿，重新打开最新内容后再编辑。

展开 **连接设置** 可以启停服务、修改服务器访问的地址与专用用户 API Key，并检查连接。`127.0.0.1` 指服务器本身。API Key 仅保存在服务端，留空保留已有密钥。

默认沿用服务器的部署配置，无需重新填写密钥。选择 **恢复部署配置** 可以撤销设置覆盖。保存配置即时应用；切换地址或后端不会搬移原有内容。知识库需要 OpenViking 后端，T3 Memory 后端仅支持记忆。
